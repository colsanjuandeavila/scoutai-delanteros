# ⚽ ScoutAI — Analizador de Rendimiento para Delanteros

Sistema de análisis de rendimiento futbolístico con Inteligencia Artificial para delanteros de fútbol.

## ¿Qué hace?

- Analiza videos cortos de delanteros de fútbol
- Evalúa 5 habilidades técnicas específicas
- Genera un informe con puntuación, fortalezas y áreas de mejora
- Proporciona un plan de entrenamiento personalizado

## Habilidades evaluadas

- ⚽ Remate y Definición
- 🎯 Control y Primer Toque
- 💨 Regate 1v1
- 🏃 Movimiento sin Balón
- ✈️ Juego Aéreo

## Tecnologías

- Python + Gradio (interfaz)
- Claude AI de Anthropic (análisis con IA)
- OpenCV (extracción de frames del video)
